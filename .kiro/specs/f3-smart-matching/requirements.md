# Requirements — F3 AI Smart Matching Engine

## Scope

สำหรับเดโม Bootcamp สามชั่วโมง เลือก F3 ให้เกษตรกรรายย่อยเห็นรายชื่อโรงงานที่รับวัสดุของตนและอยู่ในระยะขนส่งที่กำหนด ใช้รายการวัสดุ โรงงาน ราคา และระยะทางจำลองที่ป้อนล่วงหน้า ในหน้าจอเดียวภาษาไทยสำหรับ flow แบบ LINE LIFF การยืนยันตัวตนและบริการภายนอกใช้ stub

**ที่มา** — `docs/submission.md` หัวข้อ 3, 4, 7, 9 และ 10 กับ Steering ทั้งสี่ไฟล์ ใช้เพดาน 80 กม. จาก Confirmed Parameters และ Decision Log ดังนั้นตัวอย่างโรงงานที่อยู่ 85 และ 120 กม. ใน Screen 2 จะถูกกรองออก เป้าหมายธุรกรรมและจำนวนโรงงาน verified เป็นตัวชี้วัด MVP ระยะยาว

**สมมติฐานสำหรับเดโม** — ข้อกำหนดของผู้ซื้อที่ใช้คัดกรองได้แก่ ประเภทวัสดุ ปริมาณขั้นต่ำ และสถานะเปิดรับ ใช้ระยะทางที่ระบุใน fixture จัดอันดับตามราคารับซื้อจำลองต่อหนึ่งตันจากมากไปน้อย แล้วตามระยะทางจากน้อยไปมาก หากยังเท่ากันให้เรียงตามรหัสโรงงานเพื่อให้ผลคงที่

## 1. เกษตรกรค้นหาโรงงานที่รับวัสดุของตน

ในฐานะเกษตรกร ฉันต้องการรู้ว่ามีโรงงานใดรับวัสดุของฉัน เพื่อเลือกโรงงานจากเงื่อนไขที่เข้าใจได้

- **1.1** WHEN เกษตรกรส่งชนิดวัสดุที่รองรับ ปริมาณมากกว่าศูนย์ และจุดรับจากพื้นที่นำร่อง THEN the system SHALL คืนเฉพาะโรงงานที่เปิดรับวัสดุชนิดนั้น ปริมาณถึงขั้นต่ำ และระยะขนส่งไม่เกิน 80 กม.
- **1.2** WHEN มีผู้ซื้อที่เข้าเกณฑ์อยู่ที่ 80 กม. และอีกแห่งที่ 80.1 กม. THEN the system SHALL รวมแห่งแรกและตัดแห่งหลังออก
- **1.3** WHEN ข้อมูลขาดหาย ชนิดวัสดุไม่รองรับ ปริมาณไม่ใช่ตัวเลขบวก หรือจุดรับอยู่นอกพื้นที่นำร่อง THEN the system SHALL ระบุช่องที่ต้องแก้และเก็บค่าที่ผู้ใช้กรอกไว้
- **1.4** WHEN ไม่มีโรงงานผ่านเงื่อนไข THEN the system SHALL แสดง «ไม่พบโรงงานที่ตรงเงื่อนไข» พร้อมทางกลับไปแก้ข้อมูลในหน้าจอเดิม

## 2. เกษตรกรเปรียบเทียบตัวเลือก

ในฐานะเกษตรกร ฉันต้องการเห็นราคาและระยะทางด้วยหน่วยที่ชัดเจน เพื่อเปรียบเทียบโรงงานได้ในหน้าจอเดียว

- **2.1** WHEN โรงงานผ่านเงื่อนไขหลายแห่ง THEN the system SHALL เรียงตามเกณฑ์ราคา ระยะทาง และรหัสโรงงานที่ระบุข้างต้น และคืนลำดับเดิมสำหรับข้อมูลชุดเดิม
- **2.2** WHEN แสดงผล THEN the system SHALL แสดงชื่อโรงงาน ระยะทางเป็นกิโลเมตร และราคารับซื้อเป็นบาทต่อตันพร้อมป้าย «ราคาจำลอง» ในแต่ละรายการ
- **2.3** WHEN เกษตรกรส่งปริมาณเป็นตัน THEN the system SHALL แสดงหน่วยตันอย่างชัดเจน เดโมจำกัดปริมาณที่ใช้จับคู่เป็นตัน (สมมติฐาน) การรับและแปลงหน่วยท้องถิ่นขึ้นกับข้อมูลชนิดวัสดุและอยู่ในขอบเขต MVP ภายหลัง

## 3. เกษตรกรกลับมาลองใหม่ได้เมื่อโหลดข้อมูลไม่สำเร็จ

- **3.1** WHEN รายการโรงงานจำลองโหลดไม่สำเร็จหรือการเชื่อมต่อหลุดระหว่างค้นหา THEN the system SHALL แสดง «โหลดผลไม่ได้» คงข้อมูลที่กรอกไว้ และให้ลองใหม่ได้หลังเชื่อมต่อ
- **3.2** WHEN ผู้ใช้ลองใหม่หลังข้อมูลพร้อม THEN the system SHALL คำนวณจากข้อมูลที่เก็บไว้และแทนที่ข้อความผิดพลาดด้วยผลค้นหาหรือข้อความไม่พบโรงงาน

ขอบเขตนี้ครอบคลุมการจับคู่เท่านั้น F1, F2 และ F4 ใช้ข้อมูลหรือ flow จำลองเป็นอินพุต การรวมกลุ่ม การคิดค่าขนส่งและรายได้สุทธิ การจ่ายเงิน และคาร์บอนเครดิตอยู่ในงานถัดไป

## Agent design

- **หน้าที่:** ช่วยเกษตรกรหาผู้รับซื้อจากข้อมูลจำลองในพื้นที่นำร่อง และถามเฉพาะข้อมูลที่ขาด
- **โมเดล:** Strands `Agent` ใช้ Claude Sonnet 5 ผ่าน Bedrock ใน `ap-southeast-1`
- **เครื่องมือ:** `find_biomass_buyers(material, quantity_tons, province)` ตรวจชนิดวัสดุ ปริมาณเป็นตัน และจังหวัด จากนั้นกรองโรงงานจำลองตามสถานะ ชนิดวัสดุ ปริมาณขั้นต่ำ และระยะทางไม่เกิน 80 กม. เรียงตามราคาจำลองจากมากไปน้อย ระยะทางจากน้อยไปมาก และรหัสโรงงาน
- **System prompt ที่ใช้จริง:**

  > คุณคือ AgriCarbon Match AI ผู้ช่วยเกษตรกรค้นหาโรงงานรับซื้อวัสดุเหลือใช้ในพื้นที่นำร่อง ตอบเป็นภาษาไทยแบบสั้น เมื่อผู้ใช้ขอจับคู่ ให้ถามเฉพาะข้อมูลที่ขาด ได้แก่ ชนิดวัสดุ ปริมาณเป็นตัน และจังหวัดจุดรับ หากให้หน่วยอื่น ให้ขอปริมาณเป็นตันโดยไม่เดาอัตราแปลง เมื่อข้อมูลครบ ให้เรียก find_biomass_buyers และใช้ผลจากเครื่องมือเท่านั้น แสดงชื่อโรงงาน ระยะทางเป็นกิโลเมตร และราคาจำลองเป็นบาทต่อตันตามลำดับที่เครื่องมือส่งคืน ถ้าไม่พบโรงงาน ให้บอกว่าไม่พบโรงงานที่ตรงเงื่อนไขและชวนแก้ข้อมูล ห้ามรับประกันราคา การรับซื้อ หรือรายได้

- **ยังต้องทำ:** หน้าจอ LIFF ที่เก็บข้อมูลเดิมเมื่อกรอกผิดหรือไม่พบผล (1.3–1.4) และการจัดการกรณีโหลดข้อมูลล้มเหลวหรือเชื่อมต่อหลุดแล้วลองใหม่ (3.1–3.2)
